# ResumeAI

**AI-powered Resume Builder & ATS Analyzer** built with **React, Node.js, Express, MongoDB, and Tailwind CSS**.

## Features

* Resume Builder with live preview
* ATS score analysis
* Cover Letter Generator
* OTP email authentication (JWT + secure cookies)
* Responsive dark-themed dashboard

## Frontend Skills

* React (Vite)
* Tailwind CSS
* React Router DOM
* Axios
* Context API & Custom Hooks
* Responsive UI Design

## Backend Skills

* Node.js
* Express.js
* REST API Development
* MongoDB & Mongoose
* JWT Authentication
* Bcrypt Password Hashing
* Nodemailer (OTP Email Service)
* Cookie-based Authentication

## AI / Services

* Gemini API (ATS analysis & AI suggestions)

## Future Improvements

* Google Sign-In / Google Authentication
* Multiple resume templates
* PDF export support
* Resume sharing links
